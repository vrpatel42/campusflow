# Interview Notes

For every feature, be prepared to answer:

1. What customer problem does it solve?
2. Why did you choose this design?
3. What alternatives did you consider?
4. What failed while building it?
5. How did you test it?
6. How would it scale?
7. What would you improve next?

## Amazon Leadership Principles connected to this project

- Customer Obsession: prioritizing useful student workflows
- Ownership: designing, building, testing, and deploying the full system
- Learn and Be Curious: learning TypeScript, cloud services, and CI/CD
- Dive Deep: debugging API, database, and deployment issues
- Invent and Simplify: narrowing the product to essential workflows
- Deliver Results: shipping a working MVP by a fixed deadline
